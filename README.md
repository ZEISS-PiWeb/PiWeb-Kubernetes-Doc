# ZEISS PiWeb Kubernetes Documentation
This repository contains documentation snippets, sample configuration and other assets which are useful for the installation of PiWeb Kubernetes.

> [!NOTE]
> You can find the official documentation on the [ZEISS Quality Tech Guide](https://techguide.zeiss.com/en/zeiss-piweb-2027r1).

# Overview
The repository has the following structure:

* `examples` - contains sample configuration for helm chart deployments (code snippets)
* `zeiss_piweb_release.gpg` - public key to verify the helm chart signature
